# Brand Assets

Before creating, editing, exporting or displaying a logo, icon, favicon, quotation mark, social mark or branded header:

1. Inspect `brand/` and existing public/static asset folders.
2. Reuse the approved file that matches the use case.
3. Read any `BRAND-GUIDE.md` or brand README before implementation.
4. Treat GitHub brand assets as authoritative for development. Do not fetch old Drive assets unless explicitly performing a migration/audit.
5. Do **not** generate, redraw, recolor, stylize or approximate an existing logo with AI.
6. Do **not** replace a canonical asset because another file looks similar.
7. If an expected brand file is missing, stop and report the gap rather than inventing one.

Frontend Design and documentation work must follow this skill.
