# FrankiFlow Canonical Brand Assets

This folder contains the approved FrankiFlow family brand assets migrated from the shared Google Drive brand folder on 2026-09-18.

## Canonical files

- `frankiflow-full-navy-512.png` — preferred full logo for documents, quotations and general light-background use.
- `frankiflow-symbol-navy-256.png` — symbol-only mark.
- `frankiflow-icon-navy-192.png` — square/app-style icon.
- `frankiflow-favicon.ico` — browser/favicon asset.

## Rules

1. GitHub is now the development source of truth for these assets.
2. Reuse these files before creating or sourcing any alternative FrankiFlow logo.
3. Do not redraw, recolor, stretch, crop, stylize or AI-generate a replacement logo unless the user explicitly requests a new approved brand asset.
4. Product-specific brands should use their own approved repo assets when available; these files represent the FrankiFlow family/company brand.
